=== T1 CMSIS RFFT 兼容层自测 原始输出留档 ===
实现: 256 点 double radix-2 Cooley-Tukey FFT(含位反转重排)
正向: 无缩放标准 DFT; 逆向: 标准 IDFT(含 1/256)
随机源: 自实现 xorshift64, 种子 12345, 1000 组, 输入幅度 [-1,1)

[1] 往返测试
    最大绝对误差(对 float 输入) = 6.332994e-08
    最大绝对误差(对 double 真值) = 8.939514e-08
    阈值 1e-06 -> PASS

[2] 边界A x[n]==1 -> PASS
    实测 pOut[0] = 256.000000000 (期望 256.0)
    实测 pOut[1] = 0.000000000 (期望 0.0)
    其余 254 个分量最大绝对值 = 0.000000e+00 (期望 0)
    逆变换还原全 1 的最大偏差 = 0.000000e+00

[3] 边界B x[n]==delta[n] -> PASS
    实测 pOut[0] = 1.000000000 (期望 1.0)
    实测 pOut[1] = 1.000000000 (期望 1.0)
    k=1..127 实部偏离 1 / 虚部偏离 0 的最大值 = 0.000000e+00
    逆变换还原 delta 的最大偏差 = 0.000000e+00

[4] 附加诊断 -> PASS
    init(128)/init(512) 返回非零: 是
    正变换不改写输入缓冲 p: 是
    24bit 量纲(+-8388608)往返最大绝对误差 = 5.000e-01 (float 精度信息值, 不参与验收)

[5] numpy 交叉验证
    由 _compat_check.py 读 _compat_vectors.txt(输入) 与
    _compat_vectors_c.txt(C 输出), 与 numpy.fft.rfft 逐点比对,
    最大相对误差写入本文件末尾(见下方 numpy 段)

内置自测结论: 全部通过
